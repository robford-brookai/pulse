# ADR-0000: Title

- **Status**: Proposed | Accepted | Superseded by `ADR-XXXX` (link the real file when superseding)
- **Date**: YYYY-MM-DD

## Context

What forces are at play? What constraint, failure, or decision point prompted this? State the
situation, not the answer — a reader should be able to disagree with the decision on the basis of
this section alone.

## Decision

What was decided, in the active voice: "We will …". One decision per ADR.

## Consequences

What becomes easier, what becomes harder, and what is now foreclosed. Include the costs — an ADR
that lists only benefits is a sales pitch, not a record.

## Alternatives considered

Each with the reason it was not chosen. This is the section future readers actually need: it
stops a settled question from being reopened every six months.

---

**The log is append-only.** A decision that no longer holds gets a new ADR and a status flip on
the old one — never an edit. The point is the history, not the current state; the current state
is the code.
